这个网站是我整理公开表达的起点。

它以 Hugo 和 PaperMod 为基础，保持轻量、可维护的结构：文章用 Markdown 写作，作品单独归档，站点通过 GitHub Pages 发布。设计上更强调阅读体验，让内容成为页面的中心。

**技术栈**：Hugo Extended、PaperMod、GitHub Pages。

**状态**：持续更新。
